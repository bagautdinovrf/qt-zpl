# Font 0: полный диапазон квадратных размеров 4–512 точек

Этот каталог содержит независимые эталоны **Labelary Bitonal** для каждого
целого размера `^A0N,h,h`, где `h` меняется от 4 до 512. Каждый размер проверяет
один и тот же явный набор из 371 кодовой точки: английские и русские буквы,
`Ёё`, печатную Latin-1, расширенную латиницу, пунктуацию и перечисленные
распространённые символы. Это 188 839 отдельных полей `^FT`.

Набор имеет роль `validation` и не используется для подбора шрифтов, контуров
или поправок. Он не проверяет все возможные независимые пары высоты и ширины;
повороты и такие пары размеров дополнительно представлены в соседнем
`font-glyphs/`.

## Структура

- `index.json` перечисляет размеры, пути и SHA-256 отдельных манифестов,
  фактический счётчик HTTP-попыток и полноту получения всего диапазона.
- `hNNN/manifest.json` описывает страницы данного размера, отдельные ячейки,
  фактические координаты `^FT`, предупреждения API и SHA-256 файлов.
- Каждому исходному `*-labelary-bitonal.png` соответствует сохранённый `.zpl`.
  PNG записан без изменения полученных байтов, пороговой обработки или
  локальной перерисовки.

Пустые символы при малых размерах регистрируются в `blankCharacters`; это не
означает отсутствия символа в шрифте. `unsupportedCharacters` основан на
ранее подтверждённых предупреждениях Labelary, а не на отсутствии чернил.
Заголовок `X-Warnings` ограничен количеством записей, поэтому отсутствие
предупреждения само по себе не доказывает поддержку символа.

## Получение и проверка

```text
py -3 tools/font0_size_sweep.py --dry-run
py -3 tools/font0_size_sweep.py --fetch --max-requests 2500 --interval 0.6
py -3 tools/font0_size_sweep.py --check
```

Загрузка возобновляется по уже записанным манифестам и контрольным суммам.
Бюджет учитывает повторные HTTP-попытки и сохраняется между запусками.
`--first` и `--last` ограничивают диапазон для отдельного диагностического
запуска. Без `--fetch` сетевых запросов нет.

Скрипт проверяет размер PNG, глубину 1 бит, CRC, отсутствие чернил в заведомо
неподдерживаемых символах, запас до границ каждой ячейки и отсутствие чернил
вне всех ячеек. Явные `anchorX/anchorY` отделяют положение поля от ячейки,
поэтому нативный probe использует её сохранённые границы без расширения.
SHA-256 описывает
точные байты файлов; локальный `.gitattributes` отключает преобразование
переводов строк JSON/ZPL при записи в Git. Размеры страницы
не превышают 8000×8000 точек; плотность 8, 12 либо 24 dpmm выбирается только
для размещения страницы в допустимых физических размерах. Все координаты
и размеры шрифта остаются в точках принтера.

Частота не превышает двух запросов в секунду. При HTTP 429 учитывается
`Retry-After`; превышение суточной квоты или ожидание более 60 секунд
останавливает загрузку с сохранением уже полученных данных. Ограничения API:
[Labelary API](https://labelary.com/service.html#limits),
[расчёт размера битонального буфера](https://labelary.com/faq.html).

Обычная сборка и тесты не загружают этот корпус по сети и не встраивают
все его изображения в исполняемый файл. Для нативного сравнения отдельного
размера можно передать его манифест `qtzpl_font0_probe`:

```text
qtzpl_font0_probe --font candidate.ttf --manifest tests/golden/font0-size-sweep/h096/manifest.json --output-dir build_agent/build_font0_research/sweep-h096 --no-hinting --role validation
```

Все 509 размеров можно сравнить без сети и без дополнительных сборок:

```text
py -3 tools/font0_size_sweep.py --score --probe build_agent/build_agent_release/examples/qtzpl_font0_probe.exe --font build_agent/build_font0_research/QtZplFontZeroResearch-Refined.ttf --score-output build_agent/build_font0_research/size-sweep-scores --workers 3
```

`summary.json` содержит общие и отдельные для каждого размера количества
поддерживаемых, отсутствующих, точных и несовпадающих глифов, число различных
пикселей и IoU. Исполняются не более трёх нативных процессов одновременно.
Растр каждого глифа кандидата должен целиком помещаться в свою ячейку;
сумма различий всех ячеек должна совпасть с различиями полного атласа.
Кеш каждого размера привязан к SHA-256 шрифта, исполняемого файла, манифеста
и всех исходных PNG/ZPL. Изменение входов вызывает пересчёт; изменение входа
во время проверки считается ошибкой. Краткий отчёт сохраняется после
каждого завершённого размера. Полные отчёты лежат в подкаталогах `hNNN`.

Завершённые исходные страницы неизменяемы при улучшении упаковки последующих
страниц: источником геометрии остаётся сохранённый манифест. После размера
168 добавлен независимый запас 0,25 em для отрицательного левого выноса.
Предыдущие страницы прошли ту же проверку границ; незавершённая попытка
размера 169 была остановлена проверкой и затем получена с увеличенным запасом.
